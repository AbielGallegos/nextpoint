Dos experiencias, una sola fuente de verdad

El estudiante solicita. El área atiende. Ambos ven el mismo estado.

El portal del estudiante prioriza la orientación y el autoservicio. El panel administrativo es un puesto de trabajo: colas, filtros, acciones rápidas, inventario y métricas acotadas a su área.

  • {% icon 'check-circle-2' %} Sin datos sensibles: no pedimos CURP, domicilio ni documentos.

  • {% icon 'check-circle-2' %} Funciona sin internet externo para la demostración.

Recorrido de demostración (5 minutos)

  1. Estudiante entra, abre SmartMatch y encuentra el kit de redes.
  2. Solicita el préstamo y recibe un folio con historial.
  3. El gestor aprueba, entrega y registra la devolución.
  4. Se registra un reporte; el área acusa recibo y lo resuelve.
  5. Aviso, curso con progreso, KPIs y auditoría.
